02 WHERE IT STARTED
06TH
GRADE
FIRST BUILD / ARDUINO UNO

IT STARTED WITH AN ARDUINO.

Back in sixth grade, I built my first project using an Arduino Uno.

The moment something moved automatically based on what a sensor detected, electronics stopped being just a subject to me. It became something I wanted to understand, break, rebuild and eventually create with.

That curiosity eventually grew into a deeper interest in robotics, drones, embedded systems and the engineering behind intelligent machines.

03 THE ENGINEER

I WORK WHERE HARDWARE MEETS LOGIC.

I enjoy working on the hardware side of engineering while simultaneously understanding the software logic that makes the hardware useful.

My strongest interest lies in connecting both worlds: designing circuits, integrating sensors, working with communication protocols, writing and debugging system logic, and finally bringing everything together into a physical prototype.

I enjoy designing a complete system from scratch — starting with how the system should behave, deciding how the hardware should be structured, integrating the components and then testing whether the real system behaves the way it was designed.

06 ENGINEERING MINDSET

WHY BUILD IT EXPENSIVELY?

One of the things I enjoy most about engineering is taking a complicated or expensive technology and asking whether there is a simpler way to build it.

I like finding ways to bend, modify or combine technologies so that a solution becomes more practical and affordable.

For me, engineering is not only about making something technically impressive. It is also about making it useful enough that the people who actually need it can access it.
