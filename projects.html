RESEARCH EMBEDDED ML

VOC BIOMETRIC AUTHENTICATION

Exploring human VOC signatures as a biometric authentication signal.

THE PROBLEM

Conventional biometric authentication systems can be vulnerable to spoofing. We explored a different approach inspired by how biological systems identify individuals through smell.

THE APPROACH

An array of gas and VOC sensors captures the chemical signature emitted by a person. The acquired data is then used to develop an ML-based identification system.

MY ROLE

Circuit design, PCB design, sensor integration, data acquisition, testing and research-team leadership.

CHALLENGE

The sensors were not specifically designed for individual VOC identification and exhibited drift, making calibration and meaningful data acquisition a major challenge.

ROBOTICS ROS2 SURVEILLANCE

LIFELANCER ROVER

A multi-terrain disaster-response rover designed to extend its reach using an aerial companion.

THE IDEA

A rocker-bogie rover can traverse difficult terrain, but eventually it may reach an area that it cannot physically enter. LifeLancer addresses this limitation by integrating a drone with the rover.

SYSTEM

Raspberry Pi 5 acts as the central hub while ESP32-based electronics handle rover-level communication and control. LoRa can be used when longer-range communication is required.

CAPABILITIES

Autonomous navigation, human detection, obstacle avoidance, environmental sensing, live video, mapping and remote operation.

MY ROLE

Hardware integration, ESP32 and Raspberry Pi communication, sensor integration and environmental data acquisition.

IoT ML EMBEDDED

PERISHABLE PRODUCT DELIVERY SYSTEM

A distributed sensing system designed to estimate product perishability during transportation.

THE PROBLEM

Perishable goods can degrade during transportation when environmental conditions change. The project explored a system that could monitor those conditions and estimate product shelf life.

SYSTEM ARCHITECTURE

An ESP32 master communicates with multiple sensor nodes. Each slave node can represent a particular product and is identified through RFID.

ML APPROACH

The system was designed to allow initial training using data collected from the user's own container conditions before using the trained model for detection.

MY ROLE

Hardware architecture, PCB design, system logic and the ML side of the project. I worked with concepts including Decision Trees, Random Forest, Logistic Regression, KNN and ANN.
